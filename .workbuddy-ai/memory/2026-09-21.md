**Gotchas learned (important)**
- In CSS grid, `grid-column: auto` sets BOTH start and end to auto, and Chrome then
  places the item in a single 1-track column — it does NOT span full width. Use
  `grid-column: 1 / -1` to make an item span all tracks.
- Reset explicit grid-line placements (`grid-column: 8 / span 5`) in mobile media
  queries, otherwise `.row > [class^='c']` rules won't apply to them.
- Headless Chrome clamps the viewport to a **minimum 500px CSS width** — `--window-size=390`
  silently renders at 500. To verify a true 390px mobile layout use
  `--force-device-scale-factor` with a larger window instead.
- Chrome headless in this sandbox cannot reach `127.0.0.1`; screenshot via
  `file:///` URLs with `--allow-file-access-from-files` instead of a local server.
- `.reveal { opacity: 0 }` gated behind a `.js` class on `<html>` (with a `<noscript>`
  fallback) so content stays visible if JS fails — never hide content unconditionally.

**Bug found and fixed by the tests**
- `maskDestination('x')` returned `''` — the digit-stripping regex removed the letter
  and `'*'.repeat(0)` produced an empty string, i.e. a masked destination became
  indistinguishable from "no destination". Also `'@nohost'` returned `'***@nohost'`
  (leaked the domain) instead of `'***'`. Fixed the implementation: empty local **or**
  empty domain → `'***'`, and short non-email input now masks to
  `'*'.repeat(max(digits.length, destination.length, 1))`. The test now asserts the
  invariant *"a non-empty destination never masks to an empty string"*.

**Environment notes (important for next time)**
- `backend/.env` has only `SUPABASE_ANON_KEY`, so `auth.admin.createUser/listUsers`
  fail → register degrades to a local in-memory user store. This is intentional and
  surfaced via health `supabaseAdminReady: false` and diagnostics
  `storage.mode = 'local-degraded'`.
- RLS blocks `otp_codes`/`profiles` without the service role key, so
  `usingMemoryStore()` requires `hasServiceRoleKey`; the repo also detects missing
  tables per-entity (`profilesTableMissing` / `otpTableMissing`, codes `42P01` /
  `PGRST205`) and switches that entity to memory with a one-time warning.
- Optional deps must be imported via a **variable specifier**
  (`const specifier = 'redis'; await import(specifier)`) so a missing package degrades
  instead of failing at load. Type-only re-exports need
  `import type { OtpSender }` / `export type { OtpSender }` under NodeNext ESM.
- Health lives at `/api/health`, **not** `/api/v1/health`.
- Background bash jobs die when the shell finishes — use `run_in_background=true` for
  persistent servers, and start Vite with `--host 127.0.0.1` to make it reachable.
- Temporary test overrides were appended to `backend/.env` during development
